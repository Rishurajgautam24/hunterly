First public release of Hunterly.

Hunterly has two parts that work together: a Chrome extension that saves the LinkedIn profile you're looking at, and a small backend that runs on your own computer. The backend finds and checks the person's work email, writes a first draft with a local model, and tracks follow-ups.

## Install

The extension talks to the backend on your computer, so set up both.

**1. Start the backend**

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), download **Source code (zip)** below and unzip it, then in a terminal:

```
cd hunterly-0.1.0/backend
uv sync
uv run hunterly serve
```

Leave it running and open http://127.0.0.1:8765. Fill in "About me" under Settings so drafts use your name and pitch.

**2. Add the extension to Chrome**

1. Download **hunterly-extension-v0.1.0.zip** below and unzip it.
2. Go to `chrome://extensions` (Edge: `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and pick the unzipped folder.
4. Pin Hunterly Capture, open a LinkedIn profile and click the icon.

Hunterly isn't in the Chrome Web Store yet, which is why it's loaded this way. To update later, unzip the new version over the old folder and click the reload icon on `chrome://extensions`.

Optional: install [Ollama](https://ollama.com/download) and run `ollama pull llama3.2:3b` for written drafts. Without it you get a fill-in template.

## What's in 0.1.0

- Side-panel capture of the LinkedIn profile you have open (name, headline, company, location, About, up to 6 roles), saved only when you click.
- Email finder: up to 30 candidate addresses ranked by common patterns and by addresses you already know at the company, checked with the company's mail server without sending anything. Hunter.io (free plan) works as a backup when port 25 is blocked.
- Drafts written by a local model through Ollama, or a template.
- Gmail compose links, or real Gmail drafts through the Gmail API. Hunterly never sends email itself.
- Tracker with follow-ups on day 4 and day 9, bounce handling, a do-not-contact list, and CSV export.
- Works on macOS, Windows and Linux.

## Known limits

- Checking addresses needs outbound port 25, which many home networks block. The README explains the Hunter backup and the verifier VM.
- LinkedIn changes its page layout now and then. If a field comes out wrong, fix it under **Edit details** before saving.
