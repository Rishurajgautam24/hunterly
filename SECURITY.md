# Security Policy

Warmpath runs locally and stores data in `~/.ql`. If you find a vulnerability (for example in the local web app, the extension API, or credential handling), please report it privately instead of opening a public issue.

Use GitHub's **Report a vulnerability** button under the Security tab, or email rishu24oct@gmail.com. You'll get a reply within a few days.

Never post real Gmail tokens, Hunter keys, or personal contact data in issues or PRs.
